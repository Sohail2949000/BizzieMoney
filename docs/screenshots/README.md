# Screenshot checklist

No screenshots are committed yet. Existing local installations contain private
financial and account data and must not be used for public release images.

Capture screenshots only from a disposable database created for documentation.
Use fictional, non-identifying values and inspect the full viewport before
committing each image.

Required files:

| File                | View                                                    |
| ------------------- | ------------------------------------------------------- |
| `dashboard.png`     | Populated overview in desktop light mode                |
| `expenses.png`      | Expense list, month control, and multi-currency summary |
| `subscriptions.png` | Subscription list and payment status                    |
| `debts.png`         | Loans/debts view with both directions represented       |
| `settings.png`      | Collapsed settings sections without credentials         |
| `mobile.png`        | Representative 390px-wide application view              |

Requirements:

- Do not show real names, email addresses, amounts, receipts, storage
  endpoints, bucket names, access keys, session details, or backup paths.
- Do not include browser bookmarks, extensions, notifications, or desktop
  content.
- Capture both light and dark variants if additional images are added.
- Use PNG and retain readable text at the rendered README size.
- Update the main README to embed each file only after it exists.
