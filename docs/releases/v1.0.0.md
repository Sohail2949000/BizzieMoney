# BizzieMoney 1.0.0

BizzieMoney 1.0.0 is the initial public release of the self-hosted,
single-owner money manager.

## Highlights

- Responsive expense, subscription, and loan/debt tracking.
- Currency-separated summaries and regional formatting preferences.
- CSV expense import/export with preview and atomic validation.
- Private attachments with thumbnails and local or S3-compatible storage.
- Manual and scheduled verified PostgreSQL backups with guarded restore.
- Portable data export and password-confirmed financial-data purge.
- Opaque sessions, CSRF and exact-origin protection, rate limiting, and
  owner-scoped data access.
- Docker Compose installation with PostgreSQL, API, worker, web gateway, and
  persistent volumes.

## Installation

```bash
git clone https://github.com/Sohail2949000/BizzieMoney.git
cd BizzieMoney
cp .env.example .env
docker compose up -d --build
```

Set strong `POSTGRES_PASSWORD` and `SESSION_SECRET` values before starting.
See the [README](../../README.md) and
[deployment guide](../DEPLOYMENT.md).

Published v1.0.0 image tags:

```bash
docker pull sohail29490/bizziemoney:1.0.0
docker pull sohail29490/bizziemoney:1.0.0-api
docker pull sohail29490/bizziemoney:1.0.0-worker
```

## Upgrade notes

This is the first public release. Installations upgrading from development
version 0.13.0 must:

1. Create and verify a backup.
2. Preserve PostgreSQL, attachment storage, and backup storage.
3. Apply migration `0016_initial_public_release.sql` using `pnpm db:migrate`
   or the Compose migration service.
4. Restart web, API, and worker services.
5. Confirm `/health`, API readiness, worker status, and backup verification.

## Known limitations

- One owner account per installation.
- No bank synchronization, exchange-rate conversion, income accounting,
  budget forecasting, email delivery, or multi-user workspaces.
- A public demo and redacted public screenshots are not yet configured.
- Operators are responsible for TLS, host security, database maintenance, and
  tested off-host backups.
